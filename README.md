# Job Recommendation Insights
### Data Mining Project — Machine Learning with Python

Predicts whether a job seeker will be **placed (hired)** or **not placed** based on academic background, skills, and work experience. Uses supervised and unsupervised machine learning to uncover placement patterns and group candidate profiles.

**Dataset:** [Kaggle — Campus Recruitment Dataset](https://www.kaggle.com/datasets/benroshan/factors-affecting-campus-placement)  
**Records:** 215 students × 14 features  
**Target:** Binary — Placed = 1 | Not Placed = 0

## How to Run

> **Always run in order — classification and clustering depend on files generated by data_preparation.**

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/job-recommendation-insights.git
cd job-recommendation-insights
```

### 2. Download the Dataset

Download `Placement_Data_Full_Class.csv` from Kaggle:  
https://www.kaggle.com/datasets/benroshan/factors-affecting-campus-placement

Place it in the root of the project folder.

### 3. Install Dependencies

```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

### 4. Run Notebooks in Order

| Order | Notebook | What it does |
|-------|----------|-------------|
| 1st | `data_preparation.ipynb` | Loads raw CSV, encodes features, scales data, saves train/test splits |
| 2nd | `classification.ipynb` | Trains 5 classifiers, compares performance, generates all plots |
| 3rd | `clustering.ipynb` | Runs K-Means and DBSCAN, visualises clusters |

## Algorithms Used

### Classification (Supervised Learning)

| Algorithm | Purpose |
|-----------|---------|
| K-Nearest Neighbours (KNN) | Distance-based classifier, best K via cross-validation |
| Naive Bayes | Probabilistic classifier assuming feature independence |
| Support Vector Machine (SVM) | RBF kernel, finds optimal placement boundary |
| MLP Neural Network | 3-layer ANN (128→64→32), ReLU, Adam optimiser |
| **Random Forest** ← Final Model | Ensemble of 100 trees, provides feature importance |

### Clustering (Unsupervised Learning)

| Algorithm | Purpose |
|-----------|---------|
| K-Means | Partition-based clustering, best K via elbow + silhouette |
| DBSCAN | Density-based clustering, eps found via k-distance plot |

---

## Key Findings

- **CGPA / degree percentage** and **employability test score** are the strongest placement predictors
- **Work experience** provides a strong positive signal even when grades are mediocre
- **Random Forest** and **SVM** achieve the highest accuracy (~88%)
- **K-Means** (K=2) cleanly separates placed from unplaced candidates in PCA space
- **DBSCAN** reveals a tight core of highly-placeable candidates and a diffuse boundary region
